Generator for reverse-shell one-liners. Pick listener, language, and encoding; copy the payload.

Set IP and port on [revshells.com](https://www.revshells.com), then select the payload that matches what exists on the target (`bash`, `nc`, `python`, `php`, …).

## Resources

- [revshells.com](https://www.revshells.com) — interactive payload builder
- [PayloadsAllTheThings — Reverse Shell](https://github.com/swisskyrepo/PayloadsAllTheThings/blob/master/Methodology%20and%20Resources/Reverse%20Shell%20Cheatsheet.md) — static one-liners when the site is unavailable
